# Learning Questions – Java Time Travel

[Deutsch](../README.md) | [English](README.md)

This directory contains my comprehension questions, answers, and notes about historical Java web development.

I create a separate Markdown file for each learning unit. In these files, I record technical concepts I have worked through, what I have actually tried, and which questions remain open.

## Approach

1. I read relevant sections of specifications, books, and documentation.
2. I answer the comprehension questions and check my answers against the sources I used.
3. I apply what I have learned in small, reproducible examples.
4. I document only steps I have actually completed and identify tasks that are still open.
