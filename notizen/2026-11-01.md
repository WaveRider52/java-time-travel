# Notiz 01.11.2026

Heute habe ich die Umgebung für Epoche 1 gebaut: ein Servlet im Stil von Servlet 2.3, mit Ant zu einem WAR verpackt und in Docker auf Tomcat 9 gestartet. Überrascht hat mich, dass Docker bei einem erfolgreichen Build die Ausgabe von Ant ausblendet, und dass der Server Servlet-API 4.0 meldet, obwohl der Code gegen 2.3 kompiliert ist. Offen ist, wie sich Tomcat 4.1 selbst verhält und ob die DTD der `web.xml` ohne Internet gelesen wird.
